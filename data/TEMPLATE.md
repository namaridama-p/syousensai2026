# データの書き方（テンプレート）

サイトの中身のうち、よく更新するものは `data/` の JSON ファイルに分けてあります。HTML を書き換えなくても、ここを編集するだけで表示が変わります。

| ファイル | 表示される場所 |
|---|---|
| `data/shops.json` | 模擬店ページ（`shops.html`）、トップの「部活動の出展」 |
| `data/events.json` | 企画ページ（`program.html`）のタイムテーブル |
| `data/news.json` | トップと来場案内ページ（`info.html`）の「お知らせ」 |

## JSON 共通のルール

- 文字は必ず半角の `"`（ダブルクォート）で囲む。
- ブロックが2つ目以降のときは、前のブロックの `}` のあとに `,`（カンマ）を付ける。最後のブロックの後ろには付けない。
- 改行したいときは `\n` と書く。
- 書いたらページを開いて、表示が崩れていないか確認する。
  （表示されないときは、カンマや `"` の付け忘れが多いです）

## 1. 模擬店 紹介文テンプレート（data/shops.json）

`data/shops.json` の `[ ]` の中に、下のブロックをコピーして追加し、`（ ）` の部分を書き換えてください。

```json
{
  "name": "（店名）",
  "organization": "（出店団体。例: 1年生 / 〇〇部）",
  "category": "（食べ物 / 飲み物 / ゲーム / 物販 / その他）",
  "club": false,
  "place": "（場所。例: 中庭 A-1）",
  "summary": "（お店の紹介を1〜2文で）",
  "menu": [
    { "name": "（商品名）", "price": 300, "note": "（補足。不要なら行ごと省略可）" },
    { "name": "（商品名）", "price": 500 }
  ],
  "allergens": "（アレルギー表示。例: 小麦・卵・乳。なければ空 \"\" ）",
  "image": "images/shops/（ファイル名.jpg）",
  "comment": "（ひとこと）"
}
```

### 書き方のルール

- `club` は部活動の出展なら `true`、そうでなければ `false`（または行ごと省略）。`true` にするとトップページの「部活動の出展」にも表示され、模擬店ページの「部活動」ボタンで絞り込めます。
- `category` は同じ言葉にそろえる（模擬店ページの絞り込みボタンになります）。
- メニューが売り切れたら、その行に `"soldOut": true` を足す（例: `{ "name": "たこ焼き", "price": 400, "soldOut": true }`）。復活したら `true` を消すか `false` にする。
- `price` は数字だけ（`300`）。`円` は付けない。
- 画像は `images/shops/` に置いて、`image` にそのパスを書く。なければ `""`。
- `menu` が不要なら `"menu": []` にする。

## 2. 企画・タイムテーブル（data/events.json）

```json
{
  "title": "（企画名）",
  "category": "（種類。例: ステージ / 展示 / ライブ / 体験航海）",
  "day": 1,
  "start": "13:00",
  "end": "13:30",
  "place": "（場所。例: 第一体育館）",
  "organization": "（団体名。不要なら行ごと省略可）",
  "summary": "（紹介を1〜2文で）",
  "note": "（注意書き。赤字で表示されます。不要なら行ごと省略可）",
  "link": "（くわしいページの URL。不要なら行ごと省略可）"
}
```

### 書き方のルール

- `day` は `1`（11/7 土）、`2`（11/8 日）、`"both"`（両日）、`""`（未定）のどれか。未定にすると「日時は決まり次第お知らせします」の欄に出ます。
- `start` と `end` は `"09:45"` のように 24 時間で書く。未定なら `""`。
- 開催日にページを開くと、`start`〜`end` の時間帯の企画に「いま開催中」と表示されます。
- 同じ日の企画は、`start` の早い順に自動で並びます。
- `category` は同じ言葉にそろえる（企画ページの絞り込みボタンになります）。

## 3. お知らせ（data/news.json）

```json
{
  "date": "2026-11-01",
  "title": "（お知らせの見出し）",
  "text": "（本文。不要なら行ごと省略可）",
  "url": "（リンク先。例: program.html#timetable。不要なら行ごと省略可）"
}
```

### 書き方のルール

- `date` は `"2026-11-01"` の形で書く。新しい順に自動で並びます。
- トップページには新しい 3 件、来場案内ページにはすべてが表示されます。
- `url` に `https://` から始まる外部のページを書くと、新しいタブで開きます。

## 開催日時を変えるとき

開催日や公開時間は `script.js` の最初にある `window.SHOSENSAI` にまとめてあります。ここを書き換えると、カウントダウン、ヘッダーの「開催まで あと◯日」、企画ページの「いま開催中」がまとめて変わります。各ページの本文に書いてある日時は、HTML も合わせて直してください。
